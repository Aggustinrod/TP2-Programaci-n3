MortyDesk

 Este proyecto es una aplicación web desarrollada como trabajo práctico de la facultad. Permite explorar un multiverso de personajes de la serie Rick and Morty consumiendo datos de una API.



Que hace la aplicacion.

Consume la API rickandmorty api y trae personajes de su universo. El cual el usuario puede buscar indicando el nombre del personaje que desea ver.
